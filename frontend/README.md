# Frontend (React)

This folder contains the React frontend for **Minimalist Todo Manager**.

## Scripts

- `npm install`
- `npm run start`
- `npm run build`
- `npm run lint`

## Environment variables

The runtime environment is provided via `.env` (already managed by the platform). Typical variables include:

- `REACT_APP_API_BASE`
- `REACT_APP_BACKEND_URL`
- `REACT_APP_FRONTEND_URL`
- `REACT_APP_WS_URL`

Only variables prefixed with `REACT_APP_` are exposed to the browser in Create React App.
